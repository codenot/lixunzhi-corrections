# 错题记录模板入口

当前使用结构化记录，新增题目不再追加到旧章节文档。

- [记录示例](记录示例.json)：虚构的一题批改，展示题面、作答、两层错误分类及检验目标；没有错题条目，体现确认前不入库。
- [记录格式](../规范/记录格式.md)：各类型关键字段和填写规则。
- [批改与收录流程](../规范/批改与收录.md)：完整批改后等待用户选择。
- [数据操作](../规范/数据操作.md)：直接保存 JSON、确认收录、追加作答及修订。

面向用户的单题展示仍保留：原题 → 学生作答 → 参考答案 → 具体错误与证据 → 正确思路 → 不确定项。章节可选；事实与推测分开；同一题可以有多条错误。
