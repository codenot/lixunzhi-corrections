# 练习

新练习按 `科目/生成日期_批次/` 保存，每批包含 `学生卷.md` 和 `答案.md`。例如“数学-20261031-01”对应数学科2026年10月31日生成的第一批练习；此处仅说明命名，不创建示例卷。

学生卷包含练习编号、题号、完整题面和作答要求。答案卷另外保存解答、核验依据、题号到稳定题型编号的映射及来源原题；不在学生卷泄露这些内部信息。

明确交回本项目练习、且能够定位题号时，自动在相应题型文档保存作答并更新次数；批改记录只保留批改日期，作答照片按对应批改日期放入该科错题目录下的原始资料。普通作业批改仍仅在对话中进行，明确要求“只批改、不保存”时本项目练习也不写入。

题型文档是练习作答与正确次数的唯一维护位置，本目录不重复保存计数。同次提交重复上传不多计；新的真实重做可新增次数；更正判分保留同一作答标记。
