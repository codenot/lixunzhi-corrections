# 初中语文阅读理解｜常见题型、方法与能力

做阅读题，先问一句：**找到相关文字以后，题目要我对它做什么？** 有的题要你读准句意，有的要你把几句话概括成一句，还有的要你用细节解释一个判断。同一篇文章可以练不同的能力。

- **题型**是这次要交出的答案，例如“概括人物做的两件事”。
- **方法**是可以采用的做法，例如圈出题目指定的人，找出他的动作，再各用一句话写清楚。
- **能力**是孩子实际能做到的事，例如换一篇文章，也能自己找对人物的行为，概括得准确、简明。

## 常见题型对照表

| 题型 | 题目常怎么问 | 可以怎么做 | 对应能力 |
| --- | --- | --- | --- |
| **词句理解** | 这个词在文中是什么意思？这句话怎么理解？“这”指什么？ | 回到上下文，确认词义和指代。用自己的话重说一句，核对人物、范围和语气 | **理解**。把词句放回语境读准，保留原意和条件 |
| **信息提取与核对** | 文中写了哪些做法？哪一项符合原文？ | 看清题目限定的对象和范围，逐项找到对应原句。核对有没有改换对象、遗漏条件、扩大范围 | **组织信息**。按问题找到相关事实，察觉转述里的变化 |
| **事件与过程概括** | 概括人物做的两件事。补全情节发展过程 | 按指定人物或事件阶段找关键动作，再用一句话写清每件事。题目问到结果时，把结果也保留下来 | **组织信息**。从细节中提炼关键事件，能简要说清先后和变化 |
| **原因、特点与主旨归纳** | 归纳支持的理由。概括人物品质。文章主要表达了什么？ | 先列具体事实，再把意思相近的内容合并。概括主旨时，结合全文线索和关键段落，检查概括能否覆盖主要内容 | **组织信息与解释**。能从多处材料提炼共同点，再用事实支持归纳 |
| **动机、情感与言外之意推断** | 他为什么改变主意？这句话表现了怎样的心情？ | 找当时的处境、人物的话和动作，以及后来发生的变化。用一句话说明这些细节怎样支持自己的解释 | **解释与判断**。能从文中线索推出没有直接说出的意思 |
| **结构、顺序与段落作用** | 开头为什么写这个故事？这段有什么作用？说明顺序是什么？ | 先说这段写了什么，再看它引出、照应或推动了什么。区分时间先后、因果、并列、转折等关系 | **分析关系**。能说清这部分怎样参与全文的表达 |
| **标题含义与作用** | 这个标题有什么含义？以它为题有什么好处？ | 问“含义”就解释标题指向什么，结合全文看有无进一步的意味。问“作用”就说明它如何联系情节、主题或阅读感受 | **理解与分析表达**。能把标题的字面意思、文章内容和写法联系起来 |
| **词句、描写与写法赏析** | 赏析这个词。为什么这样描写？换个词行不行？ | 指出具体字词或写法，试着换词、删句或换个视角，比较画面、语气、节奏或读者感受有什么变化 | **鉴赏**。能解释写法怎样产生具体效果 |
| **比较阅读与多材料整合** | 两篇文章有何异同？结合图表和文字说说你的发现 | 先定同一个比较角度，分别找依据，再整理共同点、差异和互相补充的信息。读图表时留意单位、范围和条件 | **组织信息**。能比较多个对象，合并信息时保留重要差异 |
| **论证分析与证据评价** | 作者是怎样论证的？这个事例能证明什么？ | 分开写出观点、证据和连接两者的理由。检查证据是否相关、是否充分，结论适用于什么范围 | **解释与判断**。能看清理由怎样支持结论，知道哪里还需要补证 |
| **开放评价与迁移表达** | 你赞同他的做法吗？结合材料提建议。从另一人物视角补写 | 明确题目给的情境和限制。评价时交代标准和依据，建议要对应材料中的问题，补写要符合人物、视角和情节 | **解释与判断、表达与交流**。能用读到的信息完成新的、有依据的表达 |

## 不同文体，阅读时重点看什么

| 材料 | 阅读时关注什么 | 常见题型 |
| --- | --- | --- |
| **记叙文、小说、散文** | 人物做了什么、发生了什么变化、作者怎样表现变化 | 情节概括、人物形象、情感动机、标题含义、写法和结构作用 |
| **说明文、信息材料** | 说明的对象和特点、信息之间的关系、结论适用的条件 | 提取信息、说明顺序和方法、用词准确性、图文整合 |
| **议论文** | 作者的主张、理由和证据，结论怎样得出 | 概括论点、梳理论证思路、分析或评价论据 |
| **文言文** | 先借助积累、注释和上下文弄清谁对谁做了什么，再理解人物、事件和观点 | 释词、断句、翻译、事件概括、人物或观点比较 |
| **古诗词** | 读清诗句写了什么，想象画面，联系用词和情境体会情感 | 描绘画面、炼字赏析、分析意象和情感、比较两首诗 |

## 同一篇文章，三种问法

以《长豫事亲》为例：

1. **“翻译‘恒与曹夫人并当箱箧’。”** 这是理解词句。要从上下文补出动作是谁做的，并译出“恒”表示的经常性。 [项目原题](../../错题/语文/语文-023-文言句子翻译中的词义理解.md#q-20261109-002)
2. **“长豫是怎样侍奉双亲的？请概括两点。”** 这是筛选和概括行为。要回答长豫具体做了什么，例如在父亲出行时送到车后、常和曹夫人一起整理箱子。 [项目原题](../../错题/语文/语文-013-概括指定人物的具体事件.md#q-20261109-003)
3. **如果改问“这些行为表现了长豫怎样的特点？”** 就要从具体行为归纳品质，并说明哪些细节支持这个判断。

翻译要保留原意，概括行为要写清做了什么，归纳品质要从行为中提炼共同特点。

## 复盘错题时，找出卡住的动作

先让孩子用自己的话复述题目，再请他指出原文依据，最后看他能不能完成题目要求的处理。**如果找到了两处原文，答案却只写“他很孝顺”，就可以练习把每处原文写成一条具体行为。** 练完后换一篇难度相近的材料，请他独立再做一次，看看这一步能不能自己完成。
