# 语文到底教了什么

## 1. 知识、方法与能力

- **知识点**是具体的概念、事实、约定或规则，例如字词的含义、标点的用法、数学中的定理和公式。
- **方法**是解决一类问题的思路和步骤。比如，遇到只换了数据的同类题，我知道该按哪些步骤解答。
- **能力**是独立运用知识和方法的本领。换一份材料或换一种问法，我还能解答吗？

初中语文常要求学生把学过的知识和方法用到陌生材料里。即使熟悉了答题步骤，面对一篇新文章，仍要自己判断该用什么方法、到哪里找依据。有些学生觉得语文难，就难在这一步。

以王安石《书湖阴先生壁》中的拟人写法为例。

- **知识**　知道什么是拟人，也就是把事物当作人来写，让它们像人一样行动或表达情感。
- **方法**　赏析“两山排闼送青来”时，可以把它换成“开门就能望见青山”，比较两句话里是谁在开门。诗中的“排闼”是推开门的意思。青山仿佛主动推门而入，把一片青翠送到人眼前，读来格外亲切。
- **能力**　换一首诗，能自己找出值得细读的词句，结合上下文说清它们写出了怎样的画面、传达了怎样的感受。自己写景时，也能根据想表达的感受选用合适的写法。

## 2. 语文课的核心

**语文课教学生在听、说、读、写中运用语言文字。**

学生借助语言获取信息，理解他人的经历和感受，把零散的观察整理成想法，依据材料形成判断，再把自己的意思准确、得体地传达给别人。

读诗、读小说、读古文时，学生还会体会语言的节奏和意味，理解人在不同处境中的感受、选择和价值观。写作时，也可以借鉴读过的作品，让自己的表达更有感染力。

## 3. 语文具体学什么

### 3.1 语言与文化积累

读准字音，认清字形，掌握词义和常见搭配，学习标点、句式和修辞的用法。阅读不同文体的作品，了解各自的特点，积累文言词句和经典诗文，了解作品的文化背景。

### 3.2 阅读与思考

读一篇陌生的文章，既要读懂文字，也要能筛选和概括信息、分析关系、推断含义、评价证据，并说明自己是怎样得出结论的。

#### 理解文字和话语

读懂字面意思，辨明人物关系和限定条件，体会说话的语气。遇到陌生的词句，能结合已有的积累和上下文弄清它的意思。

#### 组织信息

围绕一个问题，从零散的信息中挑出相关内容，再加以归类、概括或比较，让别人看得出重点在哪里，不同材料的说法有哪些异同。

- **定位与筛选信息**

    - **任务**　理解细节、核对选项、查找原因、提取信息。
    - **方法**　根据问题找到原文对应的地方，核对人物、事件、范围和条件。
    - **掌握表现**　能为每个答案要点指出文中的依据，也能解释为什么舍去某条看似相关的信息。

- **复述、概括与归纳**

    - **任务**　复述故事、概括事件、提炼段意、归纳原因、概括主旨。
    - **方法**　按任务选择要点，合并重复内容，保留关键差异。
    - **掌握表现**　能用自己的话复述故事的经过，也能按题目要求，用一两句话概括主要事件。

- **分析与比较**

    - **任务**　比较不同段落或不同文章的内容、观点和写法。
    - **方法**　先确定比较角度，再分别找依据。比较内容时，梳理哪些信息相同、互补或矛盾。比较写法时，指出各自怎样写，效果有何不同。
    - **掌握表现**　能从同一角度比较两篇文章，用各自的字句说明它们的异同。

#### 解释与推断

把事实和线索联系起来，解释事情发生的原因，说明一种理解的依据，并判断现有证据足以支持什么结论。

- **梳理结构与逻辑关系**

    - **任务**　排列语句、梳理情节、分析段落作用、理清说明顺序或论证思路。
    - **方法**　找出先后、因果、转折、递进、并列或总分等关系，结合前后文判断某一段在全文中的作用。
    - **掌握表现**　能画图或用一句话说清文章中哪两处相连、怎样相连。能分清事件发生的先后顺序和因果关系。

- **推断与解释隐含意义**

    - **任务**　推断人物动机、梳理情感变化、理解标题含义、体会言外之意。
    - **方法**　写出自己的判断和文中的线索，用一句话说明这些线索怎样支持判断。
    - **掌握表现**　能区分原文直接写出的信息和自己的推断，讲清推断过程。出现新线索时，能重新审视原先的判断。

- **评价证据、论证与观点**

    - **任务**　辨析论点与论据、判断材料能否支持观点、评价选项、探讨开放性问题。
    - **方法**　区分观点、证据和推理，检查结论是否超出证据能支持的范围。
    - **掌握表现**　能解释一条证据具体支持什么，哪些说法还需要更多证据。评价或提出观点时，能讲清自己的标准和依据。

### 3.3 表达与交流

能根据对象、目的和场合，把见闻、信息、感受或观点表达清楚，并根据对方的反馈调整说法或修改作品。

- **判断与修正语言表达**

    - **任务**　辨析并修改病句、运用标点、排列语句、补写句子、修改语段。
    - **方法**　检查词语搭配、语序、标点和句子之间的衔接。
    - **掌握表现**　能在陌生语段和自己的作文里发现问题。修改时能保留原意，并说明改动解决了什么问题。

- **倾听、复述与回应**

    - **任务**　转述、采访、讨论、辩论等听说活动。
    - **方法**　记下关键信息，确认自己是否理解了对方的意思，再有针对性地回应。
    - **掌握表现**　能区分不同发言者的意见，对不清楚的细节加以追问，有条理地回应。

- **根据目的与对象调整语言**

    - **任务**　写通知、留言或演讲稿，发出邀请，提出建议，在特定情境中与人交流。
    - **方法**　先确定说给谁、要办成什么事，再选择文体、内容和语气。
    - **掌握表现**　同一件事分别写给同学和老师，能把关键信息都交代准确，并根据读者调整语气和详略。

- **观察、选材与组织篇章**

    - **任务**　看图写作、列提纲、写片段和整篇作文、安排段落顺序。
    - **方法**　确定表达重点，选择细节，安排先后和详略，写好段落之间的过渡。
    - **掌握表现**　拿到新题目能列出提纲。写完后，能说明哪些地方值得详写、哪些细节可以删去，也能解释这样的安排怎样帮助读者理解文章的重点。

- **叙事、描写与文学创作**

    - **任务**　写记叙文、写人写景、续写、改写、创意表达。
    - **方法**　选择合适的叙述视角，通过动作、对话和感官细节描绘场景，表现人物和事件的变化。
    - **掌握表现**　读者能从细节中想象场景，理解人物的特点和变化。改写时，叙述视角符合任务要求，情节与已知条件相符。

- **说明、介绍与信息转述**

    - **任务**　解说图表、撰写介绍词、说明操作流程、写事物说明文或报告。
    - **方法**　明确要说明的对象，根据需要介绍它的特征和原理，或按步骤讲清操作流程。
    - **掌握表现**　读者或听众能理解介绍的内容，或按说明完成操作。把图表转写成文字时，能准确交代必要的单位、范围和条件，说清数据反映的特点或趋势。

- **提出观点并展开论证**

    - **任务**　简要陈述观点、写评论或议论文、根据材料写作、准备辩论发言。
    - **方法**　明确主张，组织理由与证据，考虑反例和主张的适用范围。
    - **掌握表现**　面对新材料，能提出具体主张，说明每个例子怎样支持它。证据不足时能补充证据，遇到足以推翻原主张的反例时能修正主张。

- **修改与校对**

    - **任务**　修改语段、互评习作、完成作文二稿、自主订正。
    - **方法**　从读者的角度检查主要意思是否清楚、结构是否合理、证据是否充分、字句是否妥当，并根据反馈修改。
    - **掌握表现**　能对照修改前后的稿件，说清改了哪里、为什么改，以及改动后读者能更清楚地理解什么。

### 3.4 审美与文化理解

阅读时，能想象作品描绘的形象，感受语言的节奏，体会叙述方式带来的效果。遇到打动自己的地方，能结合具体字句说出原因。也能联系作品的文化背景和相关传统，理解人物的处境、选择和价值观。

- **赏析用词、句式和声音**

    - **任务**　赏析词句、分析修辞的作用、设计朗读方式、体会古诗炼字的妙处。
    - **方法**　结合语境比较不同读法的效果，或比较换词、删改前后的差异。
    - **掌握表现**　能指出具体字句，说明换一种读法或改动字句后，画面、语气或节奏发生了怎样的变化。

- **分析情节、人物与叙述**

    - **任务**　分析人物形象、情节作用和叙述视角，补写或改编故事。
    - **方法**　留意人物在不同处境下的言行，联系前后情节，并考虑叙述者能知道哪些事。
    - **掌握表现**　能用多个细节说明人物的变化。换一个叙述者时，知道哪些信息可以保留、哪些要调整。

- **鉴赏诗歌的意象与情感**

    - **任务**　描述画面、分析意象、体会情感、比较不同诗歌的表达效果。
    - **方法**　读懂诗句，想象画面，联系用词、声音和语境体会情感。
    - **掌握表现**　能指出让自己想起某幅画面的词句，并结合这些词句解释诗中流露的情感。换一首同类诗，也能找到依据。

- **联系文化语境理解作品**

    - **任务**　运用文化常识、理解典故、解释人物选择、比较古今作品。
    - **方法**　借助相关背景理解作品，再回到具体字句，检验自己的解释是否合理。
    - **掌握表现**　能举例说明某项背景知识怎样帮助自己读懂一句话或理解人物的选择，也能分清作品直接写了什么、哪些信息来自背景资料、哪些是自己的看法。

- **整本书阅读与专题研讨**

    - **任务**　阅读名著、完成名著阅读题、写读书笔记、参与讨论、推荐作品、撰写文学短评。
    - **方法**　分段阅读，记录贯穿全书的线索，带着同一个问题到不同章节寻找依据。
    - **掌握表现**　能围绕一个问题，举出书中不同章节的情节并说明它们的联系。讨论后，能根据新的依据补充或修正自己的看法。
