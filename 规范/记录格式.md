# 记录格式参考

AI 直接维护 UTF-8 JSON。每条记录保存在 `数据/<类型目录>/<id>.json`，公共字段为 `schema_version: 1`、`kind`、`id`。数据结构以本文件和实际记录为准，错误分类以 [错误分类.json](错误分类.json) 为准。

`模板/记录示例.json` 用 records 数组将几条相关记录展示在一起，仅作格式参考；实际保存时按类型拆成独立文件。示例不是学生真实数据。

## 类型与关联

| kind / 目录 | 关键字段 |
| --- | --- |
| assignment / 作业 | title、date、coverage、scope_note、expected_question_count、pages、provenance |
| material / 材料 | assignment_id、title、text、completeness、revision、provenance |
| question / 题目 | assignment_id、page_id、original_number、location、subject、chapter、prompt、content_status、material_ids、knowledge_point_ids、targets、assessment_kind、source_mistake_ids、origin、required、answer_area_visible、reference、revision、provenance |
| attempt / 作答 | question_id、submission_id、submitted_at、recorded_at、student_answer、answer_fidelity、independence、based_on、grade、assessments、supersedes_attempt_id、revision_reason、provenance |
| mistake / 错题 | question_id、admitted_attempt_id、approval、note |
| knowledge / 知识点 | subject、name、aliases |
| exercise / 练习 | title、created_at、purpose、status、question_ids、selection_note、provenance |
| revision / 修订 | entity_id、recorded_at、reason、evidence、previous_revision_id、previous、updated |

保持旧编号和旧字段，不为形式统一重写历史。可选值未知时用 null，列表没有内容时用空数组；不得填造来源、时间或学生答案。新记录照相关现有记录填写，并采用下述版本规则。

## 作业、题目与来源

- pages 每项包含 id、upload_order、printed_page、label、image_path、note。没有真实页码或无法保存原图时，相应字段为 null 并说明原因。
- provenance 保存实际来源 path、section、line、end_line；没有文件来源时可为 null 或空说明。旧记录中的 sha256 保留，新记录不要求填写校验值。
- coverage：整份作业／指定范围／范围待核实／历史错题摘录。整份作业必须先清点小题数。
- subject：语文／数学／英语；chapter 可为 null，不决定存储位置。question 与所关联的知识点必须属于同一科目；同名知识点跨科时分别建编号。作答和错题通过 question_id 继承科目，掌握索引保留 subject 并按科目分别汇总。
- material.completeness：完整／部分／缺失。需要的材料不全时，question.content_status 使用材料不全或待核实；其余为完整。
- origin：作业／生成练习／历史错题／历史练习。
- required：必答／选做／未知；answer_area_visible 使用 true 或 false。
- assessment_kind：原题／同类变式／综合迁移。targets 每项由 knowledge_point_id、error_type 组成，只列实际检验的能力。
- reference 包含 answer、solution、basis、verification、note。basis 包含 kind 和 evidence，kind 使用官方答案／老师批注／AI解答／历史记录；verification 使用已核验／待核实。

同一篇阅读材料只存一份，通过 material_ids 关联；一份作业各小题复用 assignment_id 和对应 page_id。

## 作答、错误与确认

- grade 包含 result、verification、basis、reference_answer、analysis、errors。result：正确／部分正确／错误／未作答／待核实。
- errors 每项包含 error_type、error_reason、knowledge_point_ids、location、evidence、cause。cause 包含 hypothesis、status、evidence；status：有证据支持／推测／未知。未知时 hypothesis=null，有证据支持时必须写出实际依据。
- answer_fidelity：原始作答／历史转述／部分可辨／未知。independence：独立完成／有提示／看过答案／未知。
- assessments 每项包含 knowledge_point_id、error_type、result。只评价题目 targets 中实际检验的目标；没有足够依据时留空或标待核实。
- approval 包含 mode、at、evidence；新收录 mode=用户确认，evidence 保存用户确认原话。mode=既有收录 仅用于原错题本中已存在的条目，不能用于新增错题；未保留原始确认日期时 at=null，并如实说明依据。
- exercise.purpose：检测／辅导／历史资料；status：草稿／可使用／历史资料待核验。可使用必须完成逐题核验。

每次真实作答用新的 submission_id。更正评分保留原作答，按数据操作规范追加更正记录；不替换学生原答案。

## 用版本号判断批改是否仍适用

题目和材料使用整数 revision，初始为1。新 attempt.based_on 记录批改时所依据的版本，例如：

```json
{
  "question_revision": 1,
  "material_revisions": {
    "mt-20261030-001": 1
  }
}
```

没有关联材料时 material_revisions={}。题面、条件、参考答案或检验目标变化时增加题目的 revision；共享材料变化时增加材料的 revision。

缺少 revision / based_on 的既有记录，统一视为题目和材料的初始版本1。原记录中的 question_context_hash 仅作为历史字段保留，不再依赖它计算或验证内容。

资料修订后，AI 逐项比较题目版本和全部关联材料版本。版本不同、缺少所需材料版本或无法确定依据时，旧批改暂不用于掌握判断，直到追加基于当前版本的核验结果。旧作答和旧判断保持原样，当前待核实状态体现在索引与报告。
