# 英语-028｜wake up to / fall asleep to 表伴随的介词搭配

题型编号：英语-028
知识点：wake up to + 名词 = 在……声/味中醒来；fall asleep to + 名词 = 在……声/音中入睡；to 是介词表伴随
归组范围：考查 wake up / fall asleep 后接 to + 感官名词（声音、气味、音乐、阳光），表示"伴随着……醒来/入睡"。to 在此是介词，不是不定式符号。对比：with 接状态、物品、人（fall asleep with the light on / with Mom）。
归组边界：与转移动词后 to/for（英语-026）分开；本型 to 表"伴随环境"，不表"东西转移落点"。
