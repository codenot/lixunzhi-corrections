# 英语-027｜used to do 表达过去习惯

题型编号：英语-027
知识点：used to + 动词原形，表示"过去常常做某事（现在不做了）"；与 be used to doing（习惯于）区分
归组范围：考查 used to 后接动词原形表过去习惯/状态，及其否定（didn't use to）、疑问（Did ... use to ...）形式。同时区分三个形似结构：used to do（过去常常）、be used to doing/sth.（习惯于，to 是介词）、be used to do（被用来做，被动）。
归组边界：与一般过去时本身（英语-004/019/022）分开；本型专门考"过去 vs 现在对比"的 used to 结构。

### 原题 q-20261107-006

来源：英语练习 Week 3 Unit 2 P17 第 B 节首字母填空短文（农场回忆）；原图 `原始资料/2026-11-07_01/图06.jpg`
批改日期：2026-11-07
收录依据：用户确认收录 used to 用法
知识点：used to + 动词原形表过去习惯，隐含现在已改变
原题：We ___ (use) to live on a farm... I always remember waking up... I used to jump out of bed, wash quickly and run downstairs.（短文中出现 used to 的两个例句）
学生原答案：（学生在文中看到 used to，未单独设题；用户随后追问 used to 意思，确认需收录该语法点）
参考答案与解析：
- **used to + 动词原形** = 过去常常做某事 / 过去曾经……（现在不这样了）。
  - We used to live on a farm. 我们以前住在农场。（现在不住了）
  - I used to jump out of bed. 我以前会跳下床。（现在长大了不跳了）
- 否定：didn't use to / usedn't to；疑问：Did you use to ...?
- 区分：be used to doing/sth. = 习惯于……（to 是介词，后接动名词或名词）；be used to do = 被用来做……（被动）。
批改结果：知识点收录。短文中学生未在此处出错，但经追问确认该结构需掌握。
