# 李寻之错题集

记录李寻之各科作业与考试错题，分科目整理。核心原则：**错一道，补一类**——每道题不只要订正，更要挖出错因、总结方法。

```

│   ├── 字词基础.md
│   ├── 病句修改.md
│   ├── 古诗文.md
│   ├── 现代文阅读.md
│   └── 作文与表达.md
├── 数学/

│   └── 数学/
│       └── 有理数巩固练习-2026-10-03.{md,pdf}   # 巩固练习，与错题分开存放
├── 英语/
│   └── README.md（待补充，有错题时按板块新建文件）
├── 模板/
│   └── 错题模板.md
└── README.md
```

## 组织方式

- **分科目建文件夹**：语文 / 数学 / 英语……
- **文件夹内按章节或板块分文件**，文件名用中文，如 `有理数.md`、`现代文阅读.md`。
- 一个文件只放同一科目同一章节的题，新错题追加到对应文件末尾，**不要跨科目混写**。
- **巩固练习单独存放**：基于错题生成的练习题统一放进独立的 `练习/` 目录（按科目分子目录，如 `练习/数学/`），**不要与错题文件混在同一目录**。

## 单题格式

每道题统一按下面顺序记录（完整可复制模板见 `模板/错题模板.md`）：

```markdown
## 第 N 题

**日期：** YYYY-MM-DD
**知识点：** ……
**题型：** ……（选填）

### 题目
### 我的答案      （标 ✅ / ❌）
### 正确答案
### 错误原因
### 举一反三
```

- 每题之间用 `---` 分隔。
- 文件名首行标题统一为：`# {科目}错题集 · {章节}`。
- 数学公式用 LaTeX（`\(...\)` 行内、`\[...\]` 独立公式）。

## 新增一道错题

1. 判断科目 + 章节 / 板块；
2. 对应文件不存在就新建（带标准头部）；
3. 在文件末尾追加题目，序号 = 现有题数 + 1；
4. 填齐"我的答案 / 正确答案 / 错误原因 / 举一反三"。
