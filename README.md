# 李寻之错题本

通过发送作业图片和对话，完成整份作业批改、确认收录、针对性出题，以及基于新作答的掌握评估。

**使用提示词和操作规范控制流程，AI 直接维护 JSON 数据和 Markdown 文档。** 项目不需要运行脚本或安装 Python。原来的学科文档和两份练习保留为历史来源。

## 日常怎么用

1. **发作业**：“请批改这些图片。”AI 按页检查所有题目，包含对题、错题、部分正确题、空白题和待核实题。
2. **选收录范围**：查看报告后说“全部收录”“只收第2、5题”或“除了第3题都收录”。跨页题号重复时注明页码或图号。确认前仅保存批改，不进入错题本。
3. **看总结**：“总结最近的数学错题，看看反复出现什么问题。”结论附有具体题目和作答依据。
4. **要练习**：“根据负号和括号变号的问题出5道题。”AI 先核验题目和答案，再给学生卷；答案另存。默认5题，难度参照原题，不安排每日任务。
5. **交回作答**：发练习答案或照片，尽量说明是“独立完成”“有提示”还是“看过答案”。AI 完整批改，追加作答记录，更新掌握情况；新错题仍由你确认是否收录。

章节是可选标签。主要按照学科、知识点、错误类型和历次表现检索，不需要手工整理成长篇章节文档。

## 查看当前记录

- [错题总览](报告/错题与掌握情况.md)：查看各科题数和报告入口。
- 分科查看掌握情况：[语文](报告/语文/错题与掌握情况.md)、[数学](报告/数学/错题与掌握情况.md)、[英语](报告/英语/错题与掌握情况.md)。各科分别列出知识点、错误类型、掌握状态及作答依据。
- [历史迁移与复核说明](报告/历史迁移与复核.md)：缺失材料、旧解析疑点及已复核内容。
- [历史迁移清单](数据/迁移清单.json)：逐题对应旧文件和新编号。

历史资料缺少原图，学生答案标为“历史转述”；没有将历史错题自动当成已核实的批改，也没有将旧练习当成已经做过。

## 掌握情况怎么理解

- **原题独立做对**：只说明这道原题重做通过。
- **初步掌握**：最近一次明确错误之后，至少两道不同的同类变式独立正确。
- **较稳定**：达到初步掌握后，在另一天独立完成相关迁移题。
- **待巩固**：再次出现同类明确错误。
- **掌握情况待验证**：还没有足够的有效作答判断当前掌握情况。提示后完成、看过答案、独立性未知和待核实批改不提升等级。

等级旁边保留证据，各科独立判断。同名知识点和错误类型也按科目区分；不根据错题样本计算整体正确率或“掌握百分比”。

报告另列 **原题核实** 和 **批改核验**：前者说明原题及必要材料是否已核对，后者说明某次作答的判定是否可靠。这两项与孩子的掌握情况分别记录；题面转录完整不等于原图已核实。

## 文件组织

- `数据/`：作业、共享材料、题目、作答、错题、知识点、练习卷，以及资料修订快照。每条记录一个文件，编号固定。
- `原始资料/`：新作业图片，以作业编号分目录，记录原图位置和页码。
- `报告/`：错题总览、批改报告和复核说明；各科掌握情况分别放在 `报告/语文/`、`报告/数学/`、`报告/英语/`。
- `练习/`：学生卷、答案卷，以及保留的旧练习。
- `AGENTS.md`、`规范/`、`模板/`：AI 的提示词入口、操作规则和记录示例。
- `语文/`、`数学/`、`英语/`：历史来源；新记录走结构化流程。

## 提示词放在哪里

[AGENTS.md](AGENTS.md) 是项目的 AI 操作入口，按任务引导读取批改、出题及记录规则。日常直接提出需求，不需要每次粘贴整套提示词。

AI 每次写入后会重新读取文件，核对题目数量、编号、确认记录和掌握依据；这属于按规范复核，不是程序强制校验。换到其他 AI 环境时，让它先读取项目的 AGENTS.md 及其中指向的规范。
