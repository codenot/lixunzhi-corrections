## 日常怎么用

| 你说什么 | 会发生什么 |
| --- | --- |
| “批改这份作业” | 默认在对话中按卷面页码顺序逐题给结果；错题、未答和不完整题都给完整解析。 |
| “把第2、5题记录下来” | 保存指定原题和必要来源，归入题型并更新知识点索引；范围明确就不再次确认。 |
| “把刚才不熟悉的这个知识点也收录” | 按指定范围补到对应错题或保存为独立知识点讲解，保留收录依据并更新索引。仅说“不懂”或追问时只讲解，不保存。 |
| “按这个题型出5道练习” | 保存学生卷、答案卷，答案卷记录题号与题型的对应关系。未指定数量默认5题。 |
| “这是刚才那份练习的答案” | 能明确定位后自动批改、保存作答并更新相应题型的做对次数。 |
| “只批改，不保存” | 本项目练习和讲解中的知识点补充也只在对话中处理。 |
| “总结数学哪些题型还需要练习” | 读取真实记录，在对话中展示依据；不自动生成另一份长期维护的报告。 |

错题和知识点都须明确要求收录才保存；讲解中发现不熟悉不自动收录。练习做错会留下练习作答记录，若要作为新的原错题收录，仍需你指定。普通作业或旧错题重做不会仅因匹配已有题型而自动保存。

## 目录

```text
错题/
  数学、语文、英语/
    知识点索引.md
    科目-001-具体题型名称.md
    知识点讲解/
      知识点名称.md
    原始资料/
      批改日期_批次/
        图01.jpg
        阅读材料.md（需要时）
练习/
  科目/生成日期_批次/
    学生卷.md
    答案.md
```

目录中的日期、图片及题型文件名为命名示意，不会凭空创建实例。原图按学科、批改日期及当天批次保存；同一张整页图可以被多个题型引用。延后收录沿用原批改日期。原题和练习批改记录只保留批改日期，有依据就填写，没有依据就省略。练习卷的生成批次命名保持原有规则。

同一题型按考查任务、关键解法和必要条件归组。换数字但解法结构相同可以归为一型；知识点相同但处理方式不同则分开。同型文档中的每道原题仍保留自己的编号、完整题面、学生答案和来源。可观察的错误和改法写入解析，不单设“错因”栏；学生主动说明的原因记为备注。

## 错题怎么记录

每道题按“原题 → 我的答案 → 参考答案 → 解析与纠正 → 记录信息”阅读，重点是当时怎么答、怎样改和为什么。新旧题使用相同格式，历史转述与材料缺失只作必要说明，不另设历史追溯区；已有链接锚点保留。

题型概要在文档开头写一次，练习作答另列在末尾。纯知识点补充不当作实际错题。具体模板与保存规则统一见 [统一文档格式](.agents/skills/record-mistakes/references/document-format.md)。

## 做对次数

每次新的实际作答判定正确，给对应题型增加1次；同一道题真正重做并正确也增加1次。重复上传和重新批改不会多计。判分更正保留原作答和更正说明，并调整对应次数。

部分正确、错误、未作答、待核实不增加次数。不自动区分是否独立或有提示，也不把累计次数当作已经掌握。每个次数都能回到题型文档中的具体作答。

历史原题保留历史转述、材料不全、待核实等标记；未保存的原图不补造。

## 维护方式

AI 直接读写 Markdown 和图片，不依赖项目脚本。[AGENTS.md](AGENTS.md) 登记技能位置与读取方式；具体规则在对应技能及其参考文档中。保存完成后重新读取本次文件，核对原题、来源、索引和次数。
