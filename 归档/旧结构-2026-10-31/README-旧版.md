# 李寻之错题本

通过发送作业图片和对话，完成整份作业批改、选择收录、针对性出题，以及基于新作答的掌握评估。

**批改默认只在对话中进行，不添加或修改仓库文件。** 批改和总结产生的内容，只有在明确要求记录、收录、保存或更新记录时才写入仓库；要求生成练习时，按出题流程保存学生卷、答案卷及练习记录。项目使用提示词和操作规范控制流程，AI 直接维护 JSON 数据和 Markdown 文档，不需要运行脚本或安装 Python。

## 日常怎么用

1. **批改作业**：“请批改这些图片。”AI 按页检查所有题目，包含对题、错题、部分正确题、空白题和待核实题，在对话中给出解析与收录候选。普通作业、练习回收和旧错题重做都默认只回复，不保存图片、JSON 或报告，不修改索引和掌握状态，也不分配新的持久编号。
2. **记录错题**：“把第2、5题记入错题本”“全部收录”或“除了第3题都收录”。能够明确定位的这句话就是收录确认，无需再次确认；跨页题号重复时需要能确定页码或图号。AI 只保存选中题及其必要题面、作答、材料和来源，创建或复用错题条目，更新索引与分科报告。没有选中的题不因此写入仓库。
3. **保存作答证据**：“保存这次作答并更新掌握情况”或“保存这次批改”。AI 按明确范围保存作答证据，包括范围内的正确题，并按规范更新相关记录；这不等于同意收录新的错题。只有聊天中的批改结果，不能自动成为已保存的掌握证据。
4. **看总结**：“总结最近的数学错题，看看反复出现什么问题。”结论附有具体题目和作答依据。总结或评估默认也只在对话中展示，不暗中修改索引、报告或掌握记录。
5. **要练习**：“根据负号和括号变号的问题出5道题。”AI 先核验题目和答案，再生成并保存学生卷、答案卷及练习记录。默认5题，难度参照原题，不安排每日任务。
6. **交回作答**：发练习答案或照片，尽量说明是“独立完成”“有提示”还是“看过答案”。AI 在对话中完整批改；需要保存这次作答、更新掌握情况或收录新错题时，明确说出相应要求。

章节是可选标签。主要按照学科、知识点、错误类型和历次表现检索，不需要手工整理成长篇章节文档。

## 会生成什么

- **只说“批改作业”**：只生成对话中的逐题结果、解析、建议和按页候选清单，仓库零文件变更。
- **明确“记录这些错题”**：保存选中范围的作业、题目、作答及必要材料与可取得的原图；创建或复用错题 JSON，更新索引、错题总览和对应分科报告。同一题重复收录不重复建卡。
- **明确“保存这次作答／批改”**：按指定范围保存相关题目和作答证据；新错题仍需明确收录。范围不明且无法从上下文确定时才澄清。

只收录一份作业中的部分题时，保存范围标为“指定范围”，`expected_question_count` 统计获准保存的题目数；这不影响此前在对话中对整批题目的完整批改。

## 查看当前记录

- [错题总览](报告/错题与掌握情况.md)：查看各科题数和报告入口。
- 分科查看掌握情况：[语文](报告/语文/错题与掌握情况.md)、[数学](报告/数学/错题与掌握情况.md)、[英语](报告/英语/错题与掌握情况.md)。各科分别列出知识点、错误类型、掌握状态及作答依据。

历史资料缺少原图，学生答案标为“历史转述”；没有将历史错题自动当成已核实的批改，也没有将旧练习当成已经做过。

## 掌握情况怎么理解

- **原题独立做对**：只说明这道原题重做通过。
- **初步掌握**：最近一次明确错误之后，至少两道不同的同类变式独立正确。
- **较稳定**：达到初步掌握后，在另一天独立完成相关迁移题。
- **待巩固**：再次出现同类明确错误。
- **掌握情况待验证**：还没有足够的有效作答判断当前掌握情况。提示后完成、看过答案、独立性未知和待核实批改不提升等级。

等级旁边保留证据，各科独立判断。同名知识点和错误类型也按科目区分；不根据错题样本计算整体正确率或“掌握百分比”。需要把本次表现写入掌握记录时，应明确要求保存作答或更新掌握情况。

报告另列 **原题核实** 和 **批改核验**：前者说明原题及必要材料是否已核对，后者说明某次作答的判定是否可靠。这两项与孩子的掌握情况分别记录；题面转录完整不等于原图已核实。

## 文件组织

- `数据/`：明确要求保存的作业、共享材料、题目、作答、错题、知识点、练习卷，以及资料修订快照。每条记录一个文件，编号固定。
- `原始资料/`：明确保存范围所需且实际取得的作业图片，以作业编号分目录，记录原图位置和页码。
- `报告/`：错题总览、明确要求保存的批改报告；各科掌握情况分别放在 `报告/语文/`、`报告/数学/`、`报告/英语/`。
- `练习/`：新生成的学生卷和答案卷，按科目保存。
- `AGENTS.md`、`规范/`、`模板/`：AI 的提示词入口、操作规则和记录示例。
- [历史遗留](历史遗留/)：旧的语文、数学、英语原题与解析，以及两份旧练习，供来源追溯；新记录走结构化流程。

## 提示词放在哪里

[AGENTS.md](AGENTS.md) 是项目的 AI 操作入口，按任务引导读取批改、出题及记录规则。日常直接提出需求，不需要每次粘贴整套提示词。

AI 在获准写入后会重新读取文件，核对题目数量、编号、确认记录和掌握依据；这属于按规范复核，不是程序强制校验。换到其他 AI 环境时，让它先读取项目的 AGENTS.md 及其中指向的规范。
