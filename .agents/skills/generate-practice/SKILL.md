# 练习题生成

先读[项目与存储约定](../record-mistakes/references/storage-conventions.md)。本页维护出题、答案核验、练习映射及交付流程；出卷本身不新增作答记录、不增加做对次数，也不建立原错题条目。

## 确定练习目标

1. 从用户指定的题型、原错题或上下文确定科目和范围，读取本科目知识点索引及相关题型文档、来源原题。遵循用户的题量、难度和材料要求；未指定时默认5题、难度参照原题。
2. 每道可独立批改的小题指定一个主要题型。一个知识点对应多个解法不同的题型时，依据用户目标选取；目标仍不明确才澄清。待分类条目不是正式题型，不能用于出题或计数。
3. 综合题能独立批改的小问分别编号、分别映射；否则指定主要检验题型，不把一次正确重复记给所有知识点。

## 编题与独立核验

- 依据题型的考查任务、关键解法和必要条件编题，题面应包含独立完成所需的材料、选项、图形信息和作答要求。
- 缺失原材料时可另编完整新题，但明确新题性质，不冒充原题重现；原题条件或答案尚有争议时，不直接用于确定性练习。
- 从完成的题面逐题独立解答，再与拟定答案比较。数学核对条件、单位和所有可能解；语文核对原文依据、题干限定及合理等价表达；英语核对语法、语境、拼写及合理替代答案。消除歧义或写清可接受答案后再保存。
- 历史练习重新使用前也必须复核，生成新的练习编号与映射，旧卷保持原样。

## 保存学生卷和答案卷

按项目与存储约定，使用 Asia/Shanghai 日期检查本科目当天已有批次，分配未占用的练习编号和目录。生成并保存 `练习/<科目>/<生成日期>_<批次>/学生卷.md` 和 `答案.md`。

- **学生卷**：仅包含练习编号、题号、完整题面、必要材料与作答要求。检查标题、题面、材料及可见引用，不能夹带参考答案、错误标签、解题提示或内部题型映射。
- **答案卷**：包含相同题号、参考答案、完整解析、实际核验依据，以及“练习题号 → 稳定题型编号 → 来源原题编号”的内部映射。材料另编时在此说明来源性质；映射链接指向真实题型和原题锚点。

题型文档继续作为作答证据与次数的唯一维护位置，答案卷不重复维护作答和次数。

## 保存复核与交付

重新读取两份试卷及相关映射，核对练习编号、题号、题量、材料完整性、答案与解析、主要题型和来源原题链接，确认学生卷无答案提示。核验依据应说明实际如何验证答案，不能只声称“已核验”。

完成时给出练习编号、题量及学生卷和答案卷链接。以后收到作答时使用[试卷作业批改](../grade-homework/SKILL.md)，按其中的练习回交流程保存、去重和计数。
