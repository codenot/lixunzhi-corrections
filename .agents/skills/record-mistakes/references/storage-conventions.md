# 项目与存储约定

本项目用 Markdown 维护按学科、题型归组的错题。AI 直接读写文档和图片，不新增或依赖项目脚本，不恢复按作业、题目、作答、收录拆分的 JSON 数据库。当前事实来源是 `错题/<科目>/` 中的题型文档。

业务文档路径以项目根目录为基准；技能与参考文档中的 Markdown 链接相对所在文件。此文档由批改、登记和出题技能共同引用，统一维护目录、日期及原始资料规则。

## 目录与命名

- `错题/<科目>/知识点索引.md`：知识点、别名到题型及具体原题的链接，不复制题型正确次数。
- `错题/<科目>/<科目>-001-题型名称.md`：每题型一份文档，编号在本科目内递增且固定。名称调整不改变题型编号；文件改名时同步所有入口和引用。
- `错题/<科目>/原始资料/<批改日期>_<批次>/`：例如 `2026-10-31_01/图01.jpg`。图片编号按上传顺序，真实页码和原题号另记在原题条目中；文件扩展名保持真实格式。
- `练习/<科目>/<生成日期>_<批次>/学生卷.md` 和 `答案.md`：练习编号为“科目-YYYYMMDD-两位批次”，例如“数学-20261031-01”。练习卷按生成批次命名，回交后的批改记录只写批改日期。

科目目前为语文、数学、英语。日期采用 Asia/Shanghai。原题和练习批改记录只保留“批改日期”，不另设收录、实际作答、收到、保存或整理日期字段，也不把“未知，留空”之类填写说明写进记录。批改日期没有依据时省略该字段，不能用其他日期代填。原图目录使用首次批改这批图片的日期，延后收录沿用该日期；同科同日新批次递增，补图追加序号，旧批次不重排。同一次作答重判继续引用原图，新一次真实作答使用新批次；历史图片日期无依据时用“日期未知_01”。题号、既有目录名和原始引文中的日期保留原样。

只在需要保存的范围内复制实际可取得的原图。整页图可以含多个题型，各题型引用同一文件并说明题号位置；共享阅读材料放在对应资料批次中。跨科共用的图片只存一份：优先放在主要科目下，无明显主要科目时放首次收录的科目下，其他科链接引用。没有图片文件就明确写“原图未保存”，不创建空图、假路径或假日期批次。
