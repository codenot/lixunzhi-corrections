# 统一文档格式与保存复核

创建、追加或整理题型文档，以及保存练习作答时读取本文件。这是题型文档的唯一模板；目录、日期和原图规则见[项目与存储约定](storage-conventions.md)。

题干、学生答案、老师批注分别识别。学生原答案保留错误、符号和断句；历史转述不得改称原始作答。题面、必要全文或原图缺失时在记录信息中简短说明，不能靠题名补写材料。错题以纠正与复习为目的，不常设分值、扣分规则或评分争论字段；影响题意的作答条件仍随原题保留。参考答案、老师批注、AI判断和历史解释分别标清依据，有冲突时保留。

题型文档统一采用“题型概要＋原错题＋练习作答记录”。新题和迁移旧题使用相同正文结构；格式整理保留原题、学生答案、来源、锚点、作答标记、现行结果及次数，不顺带重判。以下为格式示意，占位内容不创建成学生记录。

```markdown
# 科目-001｜具体题型名称

题型编号：科目-001

知识点：名称及索引链接

归组范围：考查任务、关键解法和必要条件

归组边界：哪些相似题应分开

累计做对次数：0

## 原错题

<a id="q-YYYYMMDD-001"></a>

### 原题 q-YYYYMMDD-001

#### 原题

完整题干、选项和必要材料或材料链接。

#### 我的答案

忠实保留学生答案；历史转述在此注明，不改写成订正答案。

#### 参考答案

参考答案；句子题尽量给完整句，有合理替代表达时注明。
历史答案注明来源性质，不因格式整理改称已核实。

#### 解析与纠正

说明考什么、如何判断、推导过程、学生写法的具体差异及怎样改正。
部分正确区分已完成与待改部分；未作答也给完整解法。
最后给出针对本题的一句易错提醒；阅读、作文按需要展开。

#### 记录信息

- 来源：真实页码、题号和原图链接；没有原图时写“原图未保存”。
- 批改日期：YYYY-MM-DD
- 结果：正确／部分正确／错误／未作答／待核实
- 收录依据：用户原话；既有题目保留原依据。

## 练习作答记录

暂无已记录的练习作答。
```

- “记录信息”的批改日期有依据才写；知识点有必要细分时补充本题知识点链接。材料缺失、答案争议和更正说明集中写在此处一次；正文必要时只简短指向该限制。
- 迁移旧题标题统一为“原题＋q编号”，保留现有 q、m 锚点以维持链接有效。不设历史追溯区，不另列旧作答、提交、材料编号或历史标注；必要来源、历史转述性质与材料缺失说明放在现有正文或记录信息中。同一结论只写一次。
- 整理时可依据已保存题面补充复习解析，明确区分本次解析与旧答案；材料不足时只解释可支持的部分，不补造原文或推断学生的心理原因。发现答案或判分需要修改时按[作答记录、计数与更正](../../grade-homework/references/submissions.md)处理。
- 经用户明确要求收录且随原题保存的知识点，写在“解析与纠正”下的可选小节“补充知识点”：写明名称及索引链接、概念或规则、适用条件、简短例子与易混点；“记录信息”中另列本次知识点的收录依据及有据可查的发现依据，保留原题的收录依据。多个知识点分别说明；知识点已独立保存时链接到讲解，只保留本题需要的说明。
- 练习记录保留练习链接、稳定作答标记、学生答案、批改日期及当前结果；短答案可用表格，长作答单列。需要纠正的题在对应记录下给出解析，更正日志与实际作答保持对应。

## 纯知识点格式

用户明确要求收录的知识点可以独立保存，不要求先有一道错题。使用以下结构，既有条目的编号与链接保留追溯；新条目不分配原题 q 编号，也不套用题型概要、“我的答案”“批改结果”或练习作答记录。

```markdown
# 知识点名称

[返回本科知识点索引](../知识点索引.md)

## 原文或例句

保留引出知识点的原文、例句或提问语境；补编的例子注明为讲解示例。

## 讲解

解释概念或规则、适用条件、例子中的用法及易混点，围绕本次指定的知识点展开。

## 记录信息

- 来源：可定位的材料位置、对话语境或已有资料链接。
- 收录依据：用户明确要求收录本知识点的原话。
- 发现依据：有依据时保留用户或孩子的原话或具体回答，说明不清楚的部分。
```

发现依据有据可查才写，用户仅要求复习时不补写不熟悉的表现。随题补充或独立保存均须把讲解中的发现与原始作答区分开；知识点收录不计入错题总数或累计做对次数。日期、原图和文件位置遵循项目与存储约定。

## 保存复核

每次保存后重新读取本次文件：核对授权范围、正文结构、原题数量与编号、题面与学生原答案保真、资料链接、索引锚点、收录依据和不确定状态。知识点补充核对发现依据与讲解语境，确认原作答结果、原题数量和次数未因补充而变化。练习核对题号映射、学生卷无提示、回交去重和判分更正后的次数。维护总数时按原题计数，不按错误标签或题型数量计数。
