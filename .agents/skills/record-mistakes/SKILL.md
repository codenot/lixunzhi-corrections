# 错题登记

先读[项目与存储约定](references/storage-conventions.md)及[统一文档格式](references/document-format.md)。本页维护收录、归型和索引流程；统一模板只维护在文档格式参考中。涉及判分、答案更正或题型合并时，再读[作答记录、计数与更正](../grade-homework/references/submissions.md)。

## 确定保存范围

- 用户指定的题目和来源清楚即为确认，直接保存选中原题及必要来源、归入题型并更新知识点索引，不再二次询问。只澄清影响选题、题面保真或归型的缺失信息。
- 将“收录新题”“补充或更正已有题”“仅整理格式”区分开。仅整理格式时保留原题、学生答案、来源、锚点、作答标记、现行结果、次数及不确定状态，不顺带重判。
- 已有批改可沿用并保留其依据及核验限制。需要新批改或完整解析时，使用[试卷作业批改](../grade-homework/SKILL.md)；材料不足时只保存有依据的内容。
- 用户指定收录纯知识点时，使用文档格式参考中的专用结构；没有实际错题或作答时，不套用学生作答与批改结果字段。

## 查重、归型与编号

保存前先读本科知识点索引，再读候选题型的定义和原题，检查题目及图片是否重复。按“考查任务＋关键解法＋必要条件”归型：只换数字且结构相同可同型；解法或条件处理显著不同则分型；选择、填空等作答形式不直接决定题型。

每道原错题只保存一处，可关联多个知识点。同型归组不能覆盖或删掉不同来源的原题。已有同一道题只补充对应条目；无法可靠归型的放 `<科目>-待分类.md`，保留所有原题信息，索引也包含它。待分类不是可用于出题或计数的正式题型。题型已可判断但全文缺失时，可以归型，同时保留材料不全标记，不能据此声称原题答案已核实。

旧题保留 q 编号和 m 收录编号。新原题使用 `q-YYYYMMDD-三位序号`，先检查全库是否占用；不再另建收录编号或 JSON。原题使用显式锚点，格式见统一模板；旧收录编号可同时保留锚点。索引按知识点列出题型链接和具体原题锚点，复用已有名称与别名，旧知识点编号仅用于追溯。

发现同型需要合并时，保留编号较早的题型；各原题及作答标记保持不变，旧题型编号记为别名，更新索引、练习映射和文档引用，按作答事件去重后重算次数。不能直接相加两个旧汇总数。

## 写入文档

1. 按项目与存储约定保存实际可取得且在授权范围内的原图，复用已有资料批次和共享图片，记录真实页码与题号。批改日期或图片日期没有依据时，分别按该参考中的规则处理。
2. 将选中原题写入对应题型文档，完整保留题面、学生原答案、参考答案及解析、结果、来源位置、收录依据和有依据的批改日期。新建和追加条目均使用统一模板，不沿用附近条目可能残留的旧布局。
3. 保留学生答案的错误、符号和断句，区分原始作答与历史转述。可观察的错误写入“解析与纠正”，不单设“错因”栏；学生主动说明的原因或作答条件原样记为备注。历史原因不可靠时保留不确定性，不推测为粗心、不会、懒惰。
4. 按知识点更新题型链接和具体原题锚点。原错题收录、历史转述和纯知识点收录均不增加累计做对次数；纯知识点不计入错题总数。

## 保存复核与交付

按统一文档格式中的保存复核要求，重新读取本次修改的每份题型文档和相关索引，对照保存前内容核对授权范围、正文结构、原题数量与编号、题面、学生答案、资料链接、锚点、收录依据及核验状态。

格式整理逐条检查本次范围内的原题，兼顾同一文件中的新旧条目；题型概要、每道原题正文和练习作答记录栏目都须符合统一模板。改名或合并时同步检查所有受影响的引用。

完成时给出保存位置与原题编号，说明仍缺失的材料或待核实项。只报告实际完成的检查；没有新作答或判分更正时，保持已有作答记录和次数。
