# 作答记录、计数与更正

保存本项目练习回交、重新判分、修改原题或参考答案、合并题型时读取本文件。图片、日期及目录见[项目与存储约定](../../record-mistakes/references/storage-conventions.md)，文档布局见[统一文档格式](../../record-mistakes/references/document-format.md)。

## 计数与稳定作答标记

只维护“累计做对次数”，不自动推断是否独立、有提示或看过答案，也不另设独立正确数。用户主动说明的作答条件可原样保留为备注。次数不直接等于知识点或题型已掌握，不设置自动等级升级。

- 明确的新一次实际作答判定为正确，增加1次；同题真正重做并正确也增加1次。
- 部分正确、错误、未作答、待核实不增加；没有作答的练习、原错题收录和历史转述不产生新的正确次数。
- 每次真实回交分配稳定提交标记，例如 `数学-20261031-01-R01`；每题作答标记为“提交标记-Q01”。同一提交的整批重传、部分重传或补充材料均复用原标记。
- 只有有依据的新实际作答才分配 R02 等新标记；不能只因又收到图片就增加一次。是否为新作答无法确定时，先澄清再计数。
- 题型文档保存作答标记、练习题号及链接、批改日期、学生答案或原图、当前判定与核验说明。汇总只统计唯一作答标记的当前有效“正确”结果。
- 判分更正保留同一作答标记和学生原答案，在批改日志中追加本次批改日期、更正原因及旧判定，更新当前判定并重算次数，不新建一次作答。
- 原题或参考答案修改时保留旧内容及更正说明；相关练习判定受影响的，先标待重新核实并暂停计数，复核后更新。不能仅改汇总数字。

## 作答证据与保存复核

回交时读学生卷、答案卷与相关题型文档，保存学生实际答案及能取得的作答图片。每条批改记录只记批改日期。作答证据只存于对应题型文档，答案卷不重复维护作答和次数。

每道可独立批改的小题按答案卷映射只计入一个主要题型。没有稳定映射或不能确定是否新作答时，先澄清相关部分，不猜配或增加次数。

短答案可用表格，长作答单列；需要纠正的题在对应记录下给出完整解析，更正日志与实际作答保持对应。保存后复读实际答案、练习链接、作答标记、批改日期、当前结果及核验说明，核对同次回交去重和更正后的次数。
