# 试卷作业批改

先读[项目与存储约定](../record-mistakes/references/storage-conventions.md)。本页维护批改和总结流程；保存作答或更正判分时，再读[作答记录、计数与更正](references/submissions.md)和[统一文档格式](../record-mistakes/references/document-format.md)。

## 确定任务与保存边界

- 普通作业批改、题目解释、直接重做原错题，默认仅在对话中完成，不写文件、不更新次数。题目与已有题型相同也不改变这一边界。
- 明确交回本项目生成的练习且题号可定位时，自动保存作答、批改并同步对应题型的做对次数。先读对应学生卷、答案卷及映射涉及的题型文档。
- 用户明确要求“只批改，不保存”时，本项目练习回交也只回复。练习无法定位时先完成可做的批改，只澄清影响保存和计数的部分，不能猜配题型。
- 明确要求保存其他作答时，仅按指定范围记录证据，不自动收录新错题。练习做错会保留作答表现；只有用户明确指定收录时，才使用[错题登记](../record-mistakes/SKILL.md)建立原错题条目。
- 同时要求批改、收录或出题时，按任务依赖使用对应技能；自动匹配技能不扩大保存授权。

## 按卷面顺序逐题批改

批改图片前先确定卷面顺序：优先依据页码（页脚“第X页 共Y页”、卷头标注）、题号的连续性与大题板块标题（如“一、选择题”“二、填空题”）、页边装订与裁切痕迹；图片文件名中的序号只作辅助，不足以单独定序。顺序能确定时，按页序、再按题号顺序逐题批改，并在每页结果开头标明页码或图号。顺序无法确定时不猜测、不重排，按图片上传顺序批改并说明“页序未能确定，以下按上传顺序”。

逐页清点所有可独立批改的小题，大题下能独立判分的小问也要单列，不得跳过、合并成一条或只挑错题讲。每题给出正确、部分正确、错误、未作答、待核实之一；读不清的题保留位置并说明。仅有“必答、完整答题区域可见且确实空白”时才判未作答。只收到部分练习答案时，其他题说明未收到，不当成漏答。

先独立求解核验再比较，主观题接受等价表达。题干、学生答案、老师批注分别识别；学生原答案保留错误、符号和断句，历史转述不得改称原始作答。题面、必要全文或原图缺失时简短说明，不能靠题名补写材料。参考答案、老师批注、AI判断和历史解释分别标清依据，有冲突时保留。

判定为错误、部分正确（不完整）或未作答的题，都要给出完整解析思路，不能只写正确答案：

- 本题考什么：考点与题干要求。
- 怎么切入：所用公式、定理、语法规则或原文依据。
- 完整解答：分步推导或多点作答的完整过程与最终答案。
- 对照作答：学生实际写法与正确思路的差异，指出错在哪一步、漏了哪个条件或要点；只依据卷面可观察的内容，不推断粗心、不会等主观原因。
- 同类题的易错提醒。

未作答同样给完整解析供补学；部分正确区分已得部分与缺失部分；正确题给答案和一句依据。以纠正与复习为目的，不常设分值、扣分规则或评分争论字段；影响题意的作答条件随原题保留。

## 保存本项目练习回交

仅在已定位本项目练习且允许保存时执行；具体去重、计数和更正规则见[作答记录、计数与更正](references/submissions.md)。

1. 确认当前回交是同次提交、补充材料、重判或新一次真实作答，再确定稳定提交标记。无法判断是否新作答时先澄清，暂不新增次数。
2. 按答案卷映射保存学生实际答案、可取得的作答图片、练习链接、作答标记、批改日期和当前判定。证据只存于对应题型文档的“练习作答记录”；答案卷不重复维护作答和次数。
3. 按唯一作答标记的当前有效结果重算累计做对次数。每道可独立批改小题只计入其主要题型，不把一次正确重复记给所有知识点。
4. 复读本次保存文件，核对实际答案、图片链接、题号映射、提交去重、更正日志和次数。只报告实际完成的检查。

## 批改交付

按“整体情况 → 按页（卷面顺序）逐题结果 → 需要处理题目的完整解析 → 建议与可收录候选”展示，逐题结果与解析保持同一题号顺序。候选使用页码或图号、原题号定位；新题在确定保存后才分配固定编号。发生保存时说明实际保存位置和计数变化。

## 总结知识点或练习表现

默认只在对话中分析；明确要求保存报告时才另存指定文档。按科目、知识点和题型引用具体原题或作答，不能用错题样本推算整体学习正确率，也不能把次数直接等同于掌握程度。

只读检查发现不一致时在对话中说明，明确要求修复后再更正。说明实际完成的复核，不声称存在未执行的程序校验。
